     2c. Bootstrap-Confidence-Intervals

     Erweiterung in backend/models_ml/poisson_goals.py (oder neue
     goal_model_bootstrap.py):
     - Funktion bootstrap_markets(model, home_xg, away_xg, n=500, 
     xg_sigma=0.15):
       - Sample home_xg' ~ Normal(home_xg, home_xg * xg_sigma), dito away, n=500
     mal.
       - Für jeden Sample: model.predict_matrix(...) + markets(...).
       - Output: {home_win: (p5, p50, p95), draw: ..., away_win: ..., over_25: 
     ..., btts: ...}.
     - xg_sigma als Setting bootstrap_xg_sigma: float = 0.15 und bootstrap_n: 
     int = 500 in Settings.

     Wo aufgerufen: in MatchPredictor.predict_from_signals für jedes der 3
     Modelle (also 3 × 500 = 1500 Samples). Performance: ~50-200 ms pro Match
     auf Standardhardware — akzeptabel; falls zu langsam, async + threadpool.

     Output-Felder im PredictionResponse (neue Sub-Struktur
     confidence_intervals):
     {
       poisson:    {home_win: [0.31, 0.35, 0.39], ...},
       negbin:     {...},
       glm_poisson:{...},
       blended:    {...}
     }

     2c. Bootstrap-Confidence-Intervals

     Erweiterung in backend/models_ml/poisson_goals.py (oder neue
     goal_model_bootstrap.py):
     - Funktion bootstrap_markets(model, home_xg, away_xg, n=500, xg_sigma=0.15):
       - Sample home_xg' ~ Normal(home_xg, home_xg * xg_sigma), dito away, n=500
     mal.
       - Für jeden Sample: model.predict_matrix(...) + markets(...).
       - Output: {home_win: (p5, p50, p95), draw: ..., away_win: ..., over_25: 
     ..., btts: ...}.
     - xg_sigma als Setting bootstrap_xg_sigma: float = 0.15 und bootstrap_n: int
     = 500 in Settings.

     Wo aufgerufen: in MatchPredictor.predict_from_signals für jedes der 3
     Modelle (also 3 × 500 = 1500 Samples). Performance: ~50-200 ms pro Match auf
     Standardhardware — akzeptabel; falls zu langsam, async + threadpool.

     Output-Felder im PredictionResponse (neue Sub-Struktur
     confidence_intervals):
     {
       poisson:    {home_win: [0.31, 0.35, 0.39], ...},
       negbin:     {...},
       glm_poisson:{...},
       blended:    {...}
     }
